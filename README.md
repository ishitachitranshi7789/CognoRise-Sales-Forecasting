# Sales Forecasting - CognoRise Internship

## Project Overview
This project analyzes historical monthly sales data and forecasts future sales using Machine Learning.

## Objectives
- Analyze historical sales trends
- Prepare time-series features using previous months' sales
- Train a Random Forest Regression model
- Evaluate predictions using MAE, RMSE, and R2 Score
- Forecast sales for the next 12 months

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
The project uses a monthly sales time-series dataset.

## Model
Random Forest Regressor with previous 12 months' sales as input features.

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Project Files
- Sales_Forecasting_CognoRise.ipynb: Complete notebook
- sales_cleaned.csv: Prepared sales data
- sales_forecasting_model.pkl: Trained model
- sales_forecast_next_12_months.csv: Future forecasts
- sales_forecast_comparison.png: Actual vs predicted graph
- sales_forecast_future.png: Future sales forecast graph

## Conclusion
The project demonstrates a basic machine learning workflow for sales forecasting using historical time-series data.
